# @Grok 群消息响应

`astrbot_plugin_grok_responder`：群聊中出现任何包含 `@grok`（不区分大小写）的消息时，使用 AstrBot 当前会话的 LLM 以 Grok 的身份生成并回复一条消息。

## 功能

- 触发条件：群消息纯文本中不区分大小写包含 `@grok`（必须带 `@` 符号），例如 `@grok`、`@Grok`、`@GROK`；@ 了昵称含 `grok` 的群成员同样会触发。
- 回复方式：调用当前会话正在使用的模型生成回复（方案 B），不 @ 消息发送者。
- 防刷屏：同一群在冷却时间内（默认 15 秒）只响应第一条触发消息，可配置为 0 关闭。
- 不干预其他消息：非触发消息完全不受影响，AstrBot 的主动回复、被 @ 回复等原有流程保持不变。
- 触发后调用 `stop_event()`，防止 AstrBot 对同一条消息再发起 LLM 请求造成重复回复。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `true` | 总开关 |
| `cooldown_seconds` | int | `15` | 同群最小响应间隔（秒），`0` 表示不限制 |
| `fallback_text` | string | `🪐 Grok 暂时无法响应，请稍后再试。` | LLM 请求失败时的兜底回复 |

## 说明

- 身份复用：插件不写死任何机器人身份。调用 LLM 时自动复用 AstrBot 已配置的
  身份提示（会话人格 persona 与 `provider_settings.prompt_prefix`），与主流程一致；
  仅追加与身份无关的输出约束（简洁、不暴露推理过程）。
- LLM 调用为无状态单轮生成，不写入 AstrBot 会话历史，不改变会话上下文。
- 匹配只针对消息文本与 At 段昵称；`grok` 字样未带 `@`（如 `grok 你好`）不会触发。
- 仅处理群聊消息（`GROUP_MESSAGE`），私聊不触发。
