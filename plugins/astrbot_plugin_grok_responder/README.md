# @Grok 群消息响应

`astrbot_plugin_grok_responder`：群聊中出现任何包含 `@grok`（不区分大小写）的消息时，将事件标记为"唤醒"并交给 AstrBot 主流程处理，由主流程调用 LLM 回复。插件仅承担触发作用。

## 功能

- 触发条件：群消息纯文本中不区分大小写包含 `@grok`（必须带 `@` 符号），例如 `@grok`、`@Grok`、`@GROK`；@ 了昵称含 `grok` 的群成员同样会触发。
- 处理方式：命中后等效于消息 @ 了机器人——由 AstrBot 主流程发起 LLM 请求并回复，**完整共享会话上下文**（对话历史、身份提示 persona、prompt_prefix、知识库等），会话历史正常记录。
- 防刷屏：同一群在冷却时间内（默认 15 秒）只触发第一条命中消息，可配置为 0 关闭。
- 无副作用：未命中的消息完全不受影响，AstrBot 原有流程（主动回复、被 @ 回复等）保持不变。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `true` | 总开关 |
| `cooldown_seconds` | int | `15` | 同群最小触发间隔（秒），`0` 表示不限制 |

## 说明

- 插件不直接调用 LLM、不产生回复结果，回复、错误处理、会话记录等全部由 AstrBot 主流程完成。
- 匹配只针对消息文本与 At 段昵称；`grok` 字样未带 `@`（如 `grok 你好`）不会触发。
- 仅处理群聊消息（`GROUP_MESSAGE`），私聊不触发。
