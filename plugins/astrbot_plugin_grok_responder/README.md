# @Grok 群消息响应

`astrbot_plugin_grok_responder`：将群聊中的 `@grok`（不区分大小写）作为当前 AstrBot 助手的唤醒别名，并交给 AstrBot 主流程回复。

## 功能

- 触发条件：群消息纯文本中包含 `@grok`，或 At 段昵称包含 `grok`。
- 输入清理：命中后从本轮模型输入中移除 `@grok`，避免模型将其理解成另一个机器人；平台原始消息不修改。
- 别名说明：只向本轮 LLM 请求追加临时说明，明确 `@grok` 是当前助手的唤醒别名；该说明不写入会话历史。
- 主流程回复：插件不直接调用 LLM、不直接发送消息，由 AstrBot 主流程处理，继续共享会话历史、群聊上下文、人格、知识库和工具。
- 防刷屏：同一群在冷却时间内默认只触发第一条命中消息。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `true` | 总开关 |
| `cooldown_seconds` | int | `15` | 同群最小触发间隔（秒），`0` 表示不限制 |

## 说明

- 仅处理群聊消息，私聊不触发。
- `grok` 未带 `@` 时不会触发。
- 纯 `@grok` 会转换为根据当前群聊上下文自然回应的请求，保证主流程获得非空提示。
