# QQ 接口

`astrbot_plugin_qq_api` 把可用操作的 QQ 接口封装成 AstrBot 工具，让 bot 在对话中读取或修改 QQ 群、机器人自身和其他用户的信息；同时支持在机器人被戳一戳时按配置回应。

## 功能

插件提供以下工具，具体内容可在插件配置页逐项开关：

| 工具 | 能力 |
| --- | --- |
| `qq_group_read` | 群列表、群资料、群成员、群公告、群文件、群荣誉、群历史消息、群精华、群系统消息、禁言列表、剩余 @全体次数 |
| `qq_group_info_write` | 修改群名、群头像、群备注，发布或删除群公告 |
| `qq_group_member_write` | 修改群名片、专属头衔、管理员，禁言、全员禁言、踢人 |
| `qq_group_file_write` | 上传、删除、移动群文件，创建、删除群文件夹 |
| `qq_group_message_write` | 设置或移除精华、撤回消息、表情回应、标记已读、处理加群请求 |
| `qq_group_lifecycle_write` | 退出群或解散群 |
| `qq_self_read` | 登录账号、在线状态、协议版本、自己的资料、收到的点赞、好友列表 |
| `qq_self_write` | 修改昵称、签名、性别、头像、在线状态、输入状态、长昵称 |
| `qq_user_read` | 陌生人或好友资料、私聊历史、指定用户的点赞资料、可疑好友申请 |
| `qq_user_write` | 修改好友备注、点赞、戳一戳、删除好友、处理好友请求和可疑好友申请 |

### 戳一戳回应

- 只响应目标为机器人的戳一戳，别人之间互戳不会触发。
- 支持随机回复文本或使用提示词触发 AstrBot 原有 LLM 回复链路。
- 可设置同一会话内同一用户的冷却时间，避免连续戳一戳造成刷屏。

## 安装

1. 将插件目录放入 AstrBot 的 `data/plugins/`。
2. 在 WebUI 的插件页启用插件。
3. 使用支持函数调用的模型，并确认当前人设没有禁用这些工具。

插件仅支持 `aiocqhttp` 平台（NapCat、go-cqhttp 等 OneBot v11 实现）。

## 配置

- **启用插件**：总开关。
- **修改类操作仅限 AstrBot 管理员**：默认开启，只允许 `admins_id` 中的 QQ 号或当前会话被标记为管理员的用户执行写入操作。
- **额外允许修改的 QQ 号**：为其他用户单独授权写入操作。
- **群信息读取 / 群资料修改 / 群成员管理 / 群文件修改 / 群消息操作 / 群生命周期**：按内容或操作逐项开关。
- **机器人自身信息读取 / 修改**：按内容或操作逐项开关。
- **其他用户信息读取 / 修改**：按内容或操作逐项开关。
- **戳一戳回应**：启用开关、回应方式、随机回复文本列表、LLM 提示词和同一用户冷却时间。
- **返回数量限制**：列表类结果的最大条数和消息内容的最大字符数。

读取类默认开启，写入类默认关闭。修改开关后，已注册的工具会在重新加载插件后按新的启用范围更新；在重新加载前，关闭的操作也会被拒绝调用。

## 使用说明

- 在群聊中省略 `group_id` 时，默认操作当前群。
- 群成员、好友、点赞等列表支持 `limit` 和 `offset` 分页，群成员还支持 `keyword` 过滤。
- 上传群文件、修改群头像和机器人头像时，只接受 `http(s)` 地址或 `base64://`、`data:` 数据，不接受服务器本地路径。
- 群公告、群文件等操作需要机器人具备相应的群权限。
- 写入操作由模型按对话内容决定是否调用，建议保持管理员限制开启，并按需开启具体操作。
- 戳一戳回应与 QQ 接口工具的开关互不影响；关闭插件总开关后两者都会停止。
