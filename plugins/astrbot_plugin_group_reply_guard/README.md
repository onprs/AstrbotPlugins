# 群聊主动回复防刷屏

`astrbot_plugin_group_reply_guard` 针对 OneBot v11 群聊的 Agent 工具循环做边界保护。

## 作用

- 群聊 LLM 请求不向模型暴露 `send_message_to_user`，普通文本只由 AstrBot 的 Respond 阶段发送一次。
- 安全提示只明确禁止 `send_message_to_user`；请求中显式提供的媒体、反应等其他工具仍可按各自规则调用。
- 在 Agent 开始时再次移除该工具，覆盖其他插件或框架后置注入的情况。
- Agent 工具循环中的纯文字进度播报不会提前发送，只保留工具媒体结果和最终文字回复。
- 保持 `display_reasoning_text` 关闭，并清空群聊事件中的推理注入槽。
- 仅移除模型工具可见性，不影响 AstrBot、RSS 插件或其他代码实际向 QQ 发送消息。
- 对响应中明确包裹在 `<think>`、`<analysis>` 或 `<reasoning>` 标签内的内容做保守过滤。
- 概率触发的主动群回复会收到仅本轮有效的上下文选择规则：当前消息只是抽样点，模型应综合本轮群历史选择自然参与的话题。
- 只有 `[Image]` 占位且没有图片描述或图像内容时，明确禁止模型猜测图片；图片语义仍由 AstrBot 的群上下文图片描述配置提供。

被 @、唤醒别名、命令、私聊、定时任务和其他非群聊事件不受主动回复上下文规则影响；私聊也不受群聊工具限制影响。

## 适用场景

当支持 Agent/推理的模型把普通群聊回复误判成主动推送时，它可能连续调用发消息工具。该插件让群聊回复回到单一发送路径，避免重复消息、QQ `retcode=1200` 连锁失败和超长工具循环。
