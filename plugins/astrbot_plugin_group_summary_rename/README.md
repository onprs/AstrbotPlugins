# 群聊总结改名

`astrbot_plugin_group_summary_rename`：定时（或手动）总结群聊消息，使用 AstrBot 配置中的 LLM 生成新群名，并通过 OneBot API 自动修改 QQ 群名称。

## 功能

- **指令开关**：在群内通过指令开启或关闭本群功能，仅群主/管理员可操作。
- **固定触发时间**：设置本群每日自动执行的时刻（HH:MM），到点自动总结并改名。
- **手动执行**：随时在群内触发一次立即总结。
- **LLM 生成**：使用 AstrBot 配置文件中当前使用的 LLM（会话 Provider），无需额外配置密钥。
- **可定制改名指导**：通过配置项 `rename_prompt` 附加"如何修改群名"的指导 prompt，例如限定风格、主题等。

## 指令

以下指令均需在群内发送，且仅群主/管理员或 AstrBot 配置的管理员可执行：

| 指令 | 说明 |
| --- | --- |
| `群名总结 开启` | 开启本群自动总结改名 |
| `群名总结 关闭` | 关闭本群自动总结改名 |
| `群名总结 时间 20:00` | 设置本群固定触发时间（HH:MM） |
| `群名总结 立即` | 立即总结一次并修改群名 |
| `群名总结 状态` | 查看本群功能状态 |

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `true` | 总开关 |
| `trigger_time` | string | `20:00` | 默认固定触发时间，各群可单独覆盖 |
| `rename_prompt` | text | 空 | 附加到 LLM 请求的改名指导 prompt |
| `history_count` | int | `50` | 每次拉取的群消息条数 |
| `name_max_len` | int | `30` | 群名最大长度（字符） |
| `check_interval` | int | `60` | 后台定时检查间隔（秒） |

## 说明

- 使用 OneBot v11 扩展 API `get_group_msg_history` 拉取群消息、`set_group_name` 修改群名，需要协议端（如 NapCat）支持；机器人需具备修改群名的权限（群主/管理员）。
- LLM 请求使用当前会话配置的 Provider（与 AstrBot 配置文件中使用的 LLM 一致），无需在插件内配置 API Key。
- 状态数据（开关、触发时间、最近执行记录）持久化于 AstrBot `data` 目录的插件 KV 存储中。
- 每个群每天最多自动执行一次，防止重复触发。
